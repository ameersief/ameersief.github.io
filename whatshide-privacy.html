Privacy Policy — WhatsHide (WhatsApp Web Privacy Shield)

Effective Date: November 25, 2026 | Version Covered: WhatsHide v6.9.1+ | Contact: ameersief100@gmail.com

1. Local Visual Privacy & Zero Chat Data Collection

Strict Local Processing

WhatsHide - WhatsApp Web Privacy Shield operates locally inside your browser on web.whatsapp.com using visual CSS filters and safe DOM overlays.

Zero Message Transmission: WhatsHide never collects, reads, logs, stores externally, or transmits your WhatsApp messages, contact names, phone numbers, media attachments, or browsing history.

Open Verification in DevTools

  • Open web.whatsapp.com and press F12 to open Chrome DevTools.
  • Open the Network tab and toggle blur settings or read messages.
  • Result: 0 bytes of conversation data leave your device.

معالجة بصرية محلية بنسبة 100%

تعمل إضافة WhatsHide محلياً بالكامل داخل متصفحك على صفحة web.whatsapp.com باستخدام مرشحات CSS وتنسيق الواجهة دون أي اتصال خارجي لقراءة المحادثات.

ميثاق الخصوصية الصفرية: لا تقرأ الإضافة رسائلك أو أسماء جهات اتصالك أو صورك أو سجل تصفحك ولا تجمعها أو ترسلها إلى أي خادم خارجي.

التحقق المفتوح عبر أدوات المطور

  • افتح web.whatsapp.com واضغط زر F12 لفتح أدوات المطور.
  • انتقل إلى تبويب الشبكة Network وجرّب التغبيش وإرسال الرسائل.
  • النتيجة: إرسال 0 بايت من بيانات المحادثات لأي جهة خارجية.

2. Permissions & PRO License Verification Scope

Browser Permissions

  • storage: Saves your visual blur intensities, custom redaction words, PIN preferences, local 48-hour reverse trial metadata, and active license state in chrome.storage.local.
  • scripting & *://web.whatsapp.com/*: Injects and refreshes privacy styles on open WhatsApp Web tabs per user toggles.

External Endpoints (PRO License Check Only)

Requests to api.gumroad.com, api.lemonsqueezy.com, and hardened Supabase single-device RPCs (verify_or_bind_device, check_device_binding, release_device) occur strictly when verifying or managing a user-entered PRO license key, sending only the license key and a randomly generated anonymous local deviceId (dev-...). Zero WhatsApp content is ever included.

صلاحيات المتصفح المطلوبة

  • صلاحية storage: تحفظ تفضيلات التغبيش، الكلمات المخصصة، رمز الحماية، بيانات الفترة التجريبية، وحالة الترخيص محلياً داخل chrome.storage.local.
  • صلاحية scripting والنطاق *://web.whatsapp.com/*: تُستخدم حصراً لتطبيق وتحديث تنسيقات الإخفاء البصري على تبويبات واتساب ويب المفتوحة.

نطاقات التحقق من الترخيص الاحترافي

يقتصر التواصل مع api.gumroad.com و api.lemonsqueezy.com ودوال التحقق المقيدة على Supabase (verify_or_bind_device و check_device_binding و release_device) على التحقق من كود التفعيل المدخل من المستخدم ومطابقته مع معرّف جهاز عشوائي مجهول (dev-...) فقط، دون أي بيانات محادثات أو معلومات شخصية.

3. Chrome Web Store Limited Use & Retention

WhatsHide strictly complies with Google Chrome Web Store User Data Policy (Limited Use):

  • We never sell or transfer user data to data brokers or advertisers.
  • We never use user data for targeted ads, profiling, or credit decisions.
  • Users can reset or remove all local settings anytime by clicking Deactivate License or uninstalling the extension.
